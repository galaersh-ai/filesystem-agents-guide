# Урок 2: Agent Skeleton

Определяем скелет агента — минимальный `ToolLoopAgent` в `lib/agent.ts`, который компилируется и отвечает (пока без инструментов и доступа к файлам).

## Проблема

Обычный вызов LLM — это один ход: вы отправляете промт и получаете ответ. Агент — это цикл. Модель генерирует ответ, и если в нём есть вызов инструмента, агент выполняет инструмент, передаёт результат обратно и даёт модели решить, что делать дальше. Это продолжается, пока модель не выдаст финальный текстовый ответ или не упрётся в лимит шагов.

Нам нужен агент, который сможет вести этот цикл. Пока — без инструментов и файлов, просто «скелет», на который дальше навесим возможности.

## Решение

`ToolLoopAgent` из AI SDK берёт на себя весь цикл. Вы даёте ему модель, инструменты и инструкции, а он управляет обменом:

```
prompt → LLM → tool call → execute tool → result → LLM → tool call → ... → final text
```

Для нашего файлового агента цикл выглядит так: пользователь спрашивает «did anyone mention pricing?», модель вызывает `bashTool` с `grep -r "pricing" calls/`, читает вывод, возможно выполняет ещё одну команду для контекста, а затем синтезирует финальный ответ. Каждый вызов инструмента — один шаг цикла. Лимит по умолчанию — 20 шагов, после чего агент останавливается.

Скелет агента в `lib/agent.ts`:

```typescript
import { ToolLoopAgent } from 'ai';

const MODEL = 'anthropic/claude-opus-4.6';

export const agent = new ToolLoopAgent({
  model: MODEL,
  instructions: '',
  tools: {}
});
```

### Как API-маршрут использует агента

Стартовый API-маршрут уже настроен на импорт вашего агента и стриминг его ответов:

```typescript
// app/api/route.ts
import { agent } from '@/lib/agent';

export async function POST(request: Request) {
  // ... extract prompt from messages ...

  const stream = await agent.stream({ prompt });
  // ... stream response back to UI ...
}
```

Маршрут вызывает `agent.stream()` с сообщением пользователя. Агент запускает цикл, стримя текст и вызовы инструментов по мере их появления. Ваша задача — экспортировать `agent` из `lib/agent.ts`, который этот маршрут сможет использовать.

## Ключевые выводы

- Агент — это цикл, а не одиночный вызов: модель вызывает инструменты до получения финального ответа (лимит — 20 шагов по умолчанию).
- `ToolLoopAgent` принимает объект с `model`, `instructions` и `tools`.
- Строка модели `anthropic/claude-opus-4.6` автоматически маршрутизируется через AI Gateway — вызов `createGateway()` не нужен.
- Вынесите модель в константу `MODEL`, чтобы легко менять её позже.
- API-маршрут ожидает именованный экспорт `export const agent`, а не экспорт по умолчанию.

## Попробуй сам

1. Запустите dev-сервер:

```bash
pnpm dev
```

2. Откройте `http://localhost:3000` и задайте вопрос, например «hello». Агент ответит простым текстом (без инструментов и доступа к файлам) — это ожидаемо.

3. Проверьте терминал на ошибки компиляции. Если `lib/agent.ts` экспортируется корректно, приложение компилируется без проблем.

!!! note "Общие ответы — это норма"
    Без инструментов и инструкций агент — просто «голый» LLM. Он пока не может исследовать файлы или отвечать на вопросы о звонках. Это исправится в следующих двух уроках.
