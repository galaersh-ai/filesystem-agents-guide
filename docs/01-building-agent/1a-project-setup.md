# Урок 1: Project Setup

Настройка проекта: разворачиваем стартовый репозиторий, связываем его с Vercel, вытаскиваем переменные окружения и разбираемся, какие файлы уже готовы, а какие предстоит создать.

## Проблема

Вы строите файлового агента для анализа транскриптов звонков. Этот паттерн можно расширить на анализ юридических документов, агентов-кодировщиков, финансовый анализ или генерацию и выполнение SQL. Прежде чем писать код, нужно правильно подготовить окружение: развернуть стартовый проект, связать его с Vercel и вытащить переменные окружения — включая OIDC-токен, который даёт доступ к песочнице.

## Решение

Для проекта используются три ключевых сервиса:

- **Vercel Sandbox** — безопасная изолированная среда для запуска недоверенного кода (bash-команд).
- **AI SDK** — унифицированный API для построения ИИ-приложений со стримингом, инструментами и агентами.
- **AI Gateway** — маршрутизирует запросы к ИИ-провайдерам с автоматическими fallback-ами, кэшированием и ограничением частоты.

### Шаг 1. Развернуть стартовый проект

Нажмите кнопку **Deploy with Vercel**, чтобы форкнуть стартер и развернуть его. Это:

1. Форкнет репозиторий в ваш GitHub-аккаунт.
2. Создаст проект Vercel, связанный с вашим форком.
3. Развернёт в продакшен с рабочей посадочной страницей.

Затем клонируйте свой форк и установите зависимости:

```bash
pnpm install
```

### Шаг 2. Связать локальный клон с Vercel

Свяжите локальный репозиторий с только что созданным проектом Vercel:

```bash
vc link
```

Выберите свою команду и опцию **Link to existing project**, затем выберите `filesystem-agent`.

### Шаг 3. Вытащить переменные окружения

Вытяните автоматически созданные переменные окружения для локального использования — это автоматически настроит OIDC-аутентификацию по токену в вашем проекте:

```bash
vc env pull
```

Теперь можно посмотреть OIDC-токен в `.env.local`.

### Шаг 4. Добавить ключ AI Gateway

Добавьте свой ключ AI Gateway API в `.env.local`:

```
AI_GATEWAY_API_KEY=your_api_key_here
```

## Обзор репозитория

Стартовый репозиторий уже содержит все необходимые файлы.

**Уже готовые файлы:**

- `app/form.tsx` — компонент, который принимает запрос пользователя, отправляет его на API-маршрут и отрисовывает стрим по мере возврата.
- `app/api/route.ts` — route handler, который вызывает агента и стримит ответ обратно в UI.
- `lib/calls/` — директория с предзагруженными демо-транскриптами звонков.

**Файлы, которые вы будете редактировать:**

- `lib/agent.ts` — здесь вы определите агента.
- `lib/tools.ts` — здесь вы определите bash-инструмент для агента.

Структура репозитория:

```
app/
├── page.tsx           # Отрисовывает компонент Form
├── form.tsx           # Ввод чата, стримит ответы из /api
├── api/route.ts       # POST-обработчик, вызывает agent.stream()
├── layout.tsx         # Корневой layout
└── globals.css        # Tailwind-стили

lib/
├── calls/             # Демо-транскрипты звонков (3 файла)
│   ├── 1.md
│   ├── 2.md
│   └── 3.md
├── agent.ts           # Пусто — вы создадите это
└── tools.ts           # Пусто — вы создадите это
```

API-маршрут уже импортирует из `lib/agent.ts`, поэтому как только вы соберёте агента, UI заработает автоматически.

## Ключевые выводы

- Стартовый проект уже содержит UI, API-маршрут и демо-данные — вам нужно написать только `lib/agent.ts` и `lib/tools.ts`.
- `vc env pull` автоматически настраивает OIDC-аутентификацию через токен — не нужно вручную управлять ключами песочницы.
- Модель будет маршрутизироваться через AI Gateway, поэтому нужен только ключ `AI_GATEWAY_API_KEY`.

## Попробуй сам

1. Проверьте, что связывание прошло успешно:

```bash
cat .env.local
```

Вы должны увидеть `VERCEL_OIDC_TOKEN` (или похожие переменные аутентификации песочницы) и ваш `AI_GATEWAY_API_KEY`.

2. Проверьте демо-данные:

```bash
ls lib/calls/
# 1.md  2.md  3.md
```

3. Загляните в транскрипт:

```bash
head -10 lib/calls/1.md
```

Вы должны увидеть метаданные звонка: ID, заголовок, участников и временные метки.

!!! note "Не запускайте dev-сервер пока"
    Приложение не скомпилируется, пока `lib/agent.ts` не экспортирует `agent`. Вы создадите это в следующем уроке.
